## 재생성

```bash
python3 -m scripts.generate_carbon_report_scenario_fixtures
```

Chrome/Chromium 설치가 필요하다(스크립트가 경로를 자동 탐색, 못 찾으면 `_find_chrome()`에
추가). 결정론적이라 항상 같은 파일이 나온다. 월 총액은 seed_mock.py와 일치하되, 경유는
실제 주유 관행대로 월 2건으로 분할되므로 개별 PDF 금액은 분할 결과다(합계는 표와 동일).
