## 기업(사장님) 플로우

### 1. 진입

**1-1. 마이데이터 동의(국세청, 중기부, 한전)**

- 사업자등록증명
- 부가세과세표준증명
- 표준재무제표증명
- 중소기업확인서
- 전기요금 납부내역

**1-2. 연료 유형 직접 체크**

- 경유·휘발유·도시가스·LPG·전기만 선택

**1-3. 다운로드 파일 업로드**

세금계산서는 OCR 또는 홈택스 엑셀 파일 업로드 둘 중 선택.

- [경유+전기만] 체크 시 → 세금계산서(연료 항목) + 전기요금고지서 (둘 다 필수)
- [도시가스+전기] 체크 시 → 세금계산서 + 전기요금고지서 + 도시가스고지서 (전부 필수)
- ["전기만"] 체크 시 → 전기요금고지서(필수), 세금계산서(선택 — 설비투자/K택소노미 리드용으로 유인 전환)

**1-4. 결손 감지**

- 예: "3~5월 도시가스 고지서가 없어요" (마이데이터엔 해당 데이터가 없음)

### 2. 감탄 AI 작동 로딩 대기 (OCR + 기존 LLM 파이프라인)

- 이 단계에서 confidence 낮은 건만 HITL 큐로 분리한다 (전체 건이 아니라 저신뢰 건만).

### 3. 업로드 결과 확인

- "이 정보는 자동으로 확인했어요" (마이데이터 5종)
- "이 정보는 직접 올려주신 자료예요" (업로드 3종)

### 4. 리포트 확인 / 반려

**4-1. 감탄 리포트 확인 (초안 리포트 즉시 노출)**

- PCAF 온실가스 배출량 & 데이터 등급 — (우디 캐릭터) 동종 업계/동일 지역 내 포지션 안내
- 추가로 보충되어야 하는 데이터 — (단디 캐릭터) "이걸 추가 제출하면 ~~효과가 있어요" 안내
- 은행 검토 요청/안내 내용 확인 (똑디 상담원 프로필)
- K택소노미 관련 내용
- 우대금리 안내 → 클릭 시 은행 상담 연결. **최종 승인 게이트는 여기뿐** — AI가 등급만으로 자동 확정하지 않는다는 CLAUDE.md §5 원칙10과 일치.
- 등급 계산 과정 확인 (자연어 + 이해하기 쉬운 요약)

**4-2. 백그라운드 은행 담당자 HITL 큐 처리 완료 시 푸시 알림**

**4-3. 반려** — 두 반려 경로를 구분해서 취급한다.

- **AI 자동 반려**: 이상한 파일·관계없는 파일·데이터 입력 누락 → 즉시 반려, 사람 개입 없음
- **은행 담당자 반려**: 우대금리 승인 요청 건이 조건 미달로 판단된 경우 → 데이터 재제출/보충 화면으로 이동

**4-4. 확정 리포트 확인 (알림 확인)**

- 최종 PCAF 등급 + 초안 대비 변동 여부 표시
- 확정된 evidence·계산 과정 전체 열람
- 우대금리·설비금융 안내(승인된 경우) → 신청/상담 진행 상태 확인
- (옵션) 탄소 이력서 QR/PDF 발급 — 원청 제출용
  - 확장 아이디어(미확정, 발표 분량 대비 투입 가치 재검토 필요): 원청사 제출용 PDF/QR/탄소 프로필 내보내기, 또는 원청사가 요구하는 리포트 양식을 입력하면 그에 맞춰 자동 생성하는 기능.

### 5. 메인 화면

- 시계열 데이터 등급 상승 그래프 — 감탄 도입 효과를 보여주는 용도
- 데이터 등급(동종 업계/동일 지역) 상위 N%
- 온실가스 배출량(동종 업계/동일 지역) 상위 N%
- 우대금리/정부지원까지 남은 진행률 N%
- 우대금리/정부지원 획득을 위한 TODO 체크리스트
- 은행 담당자와 채팅(똑디 상담원 프로필)
- 감탄 리포트 바로가기

## 은행 담당자 플로우

### 1. 로그인 → 대시보드

- 오늘 관리 기업 리스트 + 데이터 품질 이슈
- 오늘의 할 일 요약: HITL 대기 건수, 승인요청 건수

### 2. HITL 큐 (저신뢰 분류 발생 시 여기로 옴)

- 저신뢰 분류 건 목록(품목 원문 + AI 판단근거 + confidence 수치)
- 사장님이 "되묻기"에 답한 내용이 있으면 함께 표시
- 최종 확정/반려 처리 → 처리 완료 순간 사장님 쪽 4-2 "리포트 확정" 푸시 알림 자동 트리거

### 3. 승인 요청 큐 (우대금리 안내 클릭 시 여기로 옴)

기업별 신청 내역:

- K택소노미 적합 여부
- 지역이차보전(142억) 대상 여부
- 설비금융 리드

처리 결과가 사장님 쪽 "신청 진행 상태"에 반영된다. HITL 큐와는 별개 — 분류 신뢰도 문제가 아니라 금융상품 승인 문제라 큐를 분리한다.

### 4. 개별 기업 상세 페이지

- PCAF Before/After
- evidence 전체
- 트레이스 뷰([계획]/[관찰]/[행동] + confidence 수치)
- 데이터 출처 배지 그대로 노출 ("마이데이터 5개" vs "업로드 3개" 구분 유지)

### 5. 포트폴리오 뷰

- **지역·업종 집중 리스크 히트맵** — "대구경북 탄소집약 제조업 비중 X%" (금감원 스트레스테스트 대응). AI가 히트맵 전체를 보고 한 줄 캡션 자동 생성(예: "경북 표면처리 업종은 잔액 비중 18%로 크지만 WADQS 4.6으로 최저").
- **등급 상승 후보 리스트** — 클릭 시 해당 기업 데이터 입력 현황 + 감탄 리포트로 이동. 그 화면에서 "요청/조언 전송" 버튼(아웃리치용, 대출 우선순위 아님 — CLAUDE.md §5 원칙7과 일치).
- **연동 우선순위 Top 10** — 개별 기업명은 숨기고 세그먼트(업종×규모) 단위로 먼저 노출, 담당자가 클릭해야 개별 기업 리스트가 보이는 2단계 공개. 순위·세그먼트·대상기업수·예상임팩트(WADQS 개선폭)·예상성공률 표시. AI가 순위표를 읽고 담당자용 브리핑 문장 생성(예: "이번 분기 우선 접촉 대상 1순위는 구미 금속가공·10인 이하 23개사").
- **리드 리스트** — K택소노미 적합 기업 / 설비투자 탐지 기업. 정렬 기준은 데이터 완전성만(성과·감축실적 기반 정렬 금지 — CLAUDE.md §5 원칙7).

### 6. 규제 대응 리포트

- 시계열 금융배출량 등급 상승 표(포트폴리오 전체 추이)
- 검증 오차율
- 금감원 「기후리스크 관리 지침서」 4단계(거버넌스·전략·리스크평가·공시) 구조로 자동 섹션 구성

### 7. 품질 이슈 로그 (열람 전용)

- 자동으로 반려된 업로드 이력

### 8. 감사 대응 근거 패키지

- 기업/기간을 지정하면 관련 `trace_logs`(계획/관찰/행동) + `classifications.evidence` + 원본 전표를 시계열로 묶어 조회
- 내보내기: PDF(서술형 감사보고서), CSV(원자료 재검증용)
