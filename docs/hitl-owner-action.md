# 장면③ HITL 카드 — 사장님 액션 추가 논의

## 문제

`/owner` 장면③(AI 분류)에서 "검토 예정(HITL)" 뱃지가 붙은 카드를 봐도, 사장님이
할 수 있는 게 아무것도 없다 — 그냥 "은행 담당자가 볼 거예요" 뱃지만 보고
넘어가야 해서 무력하게 느껴짐.

## 발견한 것 — 확신도 높은데 검토필요인 케이스의 실제 원인

"가스요금" 카드가 `AI 확신도 93%`인데도 `검토 예정`으로 뜨는 걸 보고 모순처럼
보였는데, DB의 evidence 필드를 보면 이유가 분리되어 있다:

```
evidence = "[R011] 도시가스는 고정연소로 처리 | 도시가스 사용량 미기재 — 금액 역산 대신 사람 검토"
```

즉:
- **분류(Scope/연료)는 룰이 93%로 확신** — 이건 맞음
- **계산(물량 역산)이 별개 사유로 막힘** — 도시가스는 금액만으론 정확한 사용량을
  역산하기 어려워서 사람 확인이 필요하다는, 분류 신뢰도와 무관한 사유

지금 화면은 이 두 사유를 구분 없이 똑같은 "검토 예정" 뱃지 하나로 뭉뚱그려
보여주고, 진짜 사유는 카드를 펼쳐야만(판단 근거) 보인다. 그래서 확신도
뱃지와 검토 뱃지가 모순처럼 보임.

## 왜 "사장님이 직접 확정"은 안 되는가

CLAUDE.md §9 원칙상 최종 검토자는 은행 담당자다(사장님이 여신 관련 판단을
직접 확정하는 구조는 고영향 AI 회피 원칙에 어긋남). 다만 검토 사유 대부분이
**"정보 부족"**(가스 사용량 미기재, 연료 종류 애매함)이라, 사장님이 정보를
보태는 것 자체는 이미 CLAUDE.md에 있는 패턴과 같은 결(§3-2 "가스 고지서
2장만 더 연동하면 등급 상승" 능동 안내)이라 확정 권한 없이도 사장님이 할 수
있는 행동이 있다.

## 옵션 2가지

### A. 이유만 명확히 노출 (프론트 전용, 지금 바로 가능)
카드에 "가스 사용량 정보가 없어 은행 담당자가 확인 중이에요"처럼 사유를
바로 보이게 함. 새 API 불필요. 다만 사장님이 실제로 할 수 있는 행동은 여전히
없고, "왜 기다려야 하는지"만 명확해짐 — 무력감 자체는 완전히 해소 안 됨.

### B. 정보 보완 입력 기능 추가 (백엔드 신규 엔드포인트 필요, 추천)
- 물량 미기재로 검토필요인 건(가스·전기 등): "실제 사용량 입력" 인풋을
  카드에 바로 노출 → 입력 즉시 재계산되어 자동확정으로 전환될 수 있음
- 연료 종류가 애매해서 검토필요인 건(예: "유류대금"): "경유 / 휘발유 / 잘 모름"
  중 선택하는 퀵 액션 → 선택 즉시 재분류
- 필요 작업: `PATCH /classify/{voucher_id}` 류 엔드포인트 신설, 사장님 입력값을
  받아 `db/calc_engine.compute_emission` 또는 재분류 로직 재호출 → Classification
  갱신. 프론트는 카드 안에 조건부 인풋/버튼 추가.
