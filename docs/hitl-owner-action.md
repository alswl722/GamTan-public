# 되묻는 HITL — 사장님 정보 보완 입력 (결정 완료, 설계 확정)

> 진행 상태·구현 상세는 `docs/v1-plan.md` §7-3이 정본. 이 문서는 배경과 확정된
> 정책만 남긴다.

## 문제

`/owner` 장면③(AI 분류)에서 "검토 예정(HITL)" 뱃지가 붙은 카드를 봐도 사장님이
할 수 있는 게 없었다. 원인을 보면 검토 사유 대부분이 **분류 신뢰도 문제가
아니라 "정보 부족"**이다 — 예: 도시가스 evidence가 다음처럼 두 사유로 나뉨.

```
[R011] 도시가스는 고정연소로 처리 | 도시가스 사용량 미기재 — 금액 역산 불가
```

분류(Scope/연료)는 룰이 이미 확신하고 있고, 계산(물량 역산)만 별개 사유로
막혀 있다. 이런 케이스는 CLAUDE.md §9(최종 검토자는 은행 담당자, 사장님의
직접 확정은 고영향 AI 회피 원칙 위반)를 지키면서도, 사장님이 부족한 정보를
채워 넣는 것 자체는 허용할 수 있다 — §3-2 "가스 고지서 2장만 더 연동하면
등급 상승" 같은 능동 안내와 같은 결.

## 결정: 정보 보완 입력 기능 (옵션 B)

- **사장님이 입력한 값은 최종 판정이 아니다.** `status`는 여전히
  `review_required`로 남는다 — 담당자가 확정할 때 참고할 재료일 뿐.
- **재계산은 입력 즉시 하지 않는다.** 저장만 해두고, 담당자가 확정할 때
  `_recalculate()`가 이 값을 반영한다.
- **대상**: 물량 미기재(전기·도시가스 등 `_QUANTITY_ONLY`)와 연료 종류 애매
  (예: "유류대금") 두 케이스 모두 동일 원칙(입력만 저장 → 담당자 확정 시 반영).

구현 상세(신규 컬럼, API, 재계산 로직, 프론트 카드 UI)는 `docs/v1-plan.md`
§7-3 참고.
