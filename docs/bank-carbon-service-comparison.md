## 1. 은행별 서비스 상세

### KB국민 — KB탄소관리시스템

- **데이터 소스**: 한국전력 오픈 API 연동 + 자체개발 'KB AI-OCR'로 전기 고지서 자동인식("금융권 최초" 타이틀). [전자신문](https://www.etnews.com/20241010000081) · [에너지코리아뉴스](https://www.energykorea.co.kr/news/articleView.html?idxno=62871)
- **대상**: KB국민은행 기업인터넷뱅킹 이용 법인 고객 누구나, 무료
- **기능**: 업종별 배출시설 목록 자동생성 → 배출량 산정 원스톱, 감축목표 대비 실적 추적, 계열사·자회사·협력사 배출량 통합관리
- **Scope 커버리지**: 보도자료가 전부 "에너지 사용량 기반"이라고만 표현. 가스·유류 등 연료 데이터 처리 언급은 어느 기사에도 없음 → Scope 1(연료 연소) 처리 여부 미확인이지만, 전기 중심 정황이 강함
- **전략적 시사점**: "계열사·협력사 통합관리" 기능은 원청 대기업이 자기 공급망을 관리하는 용도에 가까움. 감탄의 타깃(공급망 실사를 통과해야 하는 2·3차 영세 벤더)과는 반대편 포지션

### 신한 — 탄소배출량 측정관리시스템 + ESG우수상생지원대출

- **탄소배출량 측정관리시스템**: 2022년 시중은행 최초로 금융배출량(Scope 3 Cat.15) 측정시스템 도입. PCAF 지침 반영, 6개 산업군·약 230조원 금융자산 대상 산업별·고객별 분석. [한경 2022](https://www.hankyung.com/article/2022072164871)
- **성격**: 은행이 보유한 여신 포트폴리오를 하향식(top-down)으로 추정하는 은행 내부 공시용 시스템 — 기업이 로그인해서 쓰는 화면이 아님
- **ESG우수상생지원대출**: 신한이 자체 평가로 선정한 ESG 우수기업 + 그 추천 협력사에 0.2~0.3%p 금리우대. [매일일보](https://www.m-i.kr/news/articleView.html?idxno=806580) · [한경 2021](https://www.hankyung.com/economy/article/2021031278261)
- **한계**: 협력사 선정이 "우수기업의 추천" 방식 — 실측 데이터 기반이 아니라 관계 기반 대출 상품에 가까움. 협력사 자체의 탄소배출량 실측·검증 절차는 확인 안 됨

### 하나 — 기업 ESG 라운지 온실가스 배출량 산정

- **개발 이력**: 2023년 이화여대 공동개발 + 금감원 ESG 전문가 검증을 거친 산정 로직. [뉴데일리](https://biz.newdaily.co.kr/site/data/html/2025/02/05/2025020500227.html)
- **서비스화**: 2025년 2월 기업뱅킹 내 'ESG 라운지' 메뉴로 신설, ESG컨설팅 신청·온실가스 산정·ESG 교육을 한 메뉴에 통합. [더팩트](https://news.tf.co.kr/read/economy/2175985.htm) · [그린포스트코리아](https://www.greenpostkorea.co.kr/news/articleView.html?idxno=223863)
- **입력 방식**: "에너지 사용량 등 간단한 정보로 스스로 산출" — 명시적으로 사용자 직접 입력 기반
- **여신 연계**: 2025년 3월 ESG 평가 인정기업 대상 우대금리 특판 '하나 중견기업 밸류업 대출' 출시 — 여신상품 직접 연계 사례 있음
- **평가**: 산정 로직의 학술적 검증(이대+금감원)은 신뢰도 측면에서 강점이지만, 입력 부담은 그대로 남음

### 우리 — 녹색보증 (기보 협약보증)

- **구조**: 우리은행·기술보증기금(기보)·농협은행 3자가 '녹색정책금융 이차보전지원 협약보증' 체결. 기보가 탄소가치평가·감축평가·K-택소노미 적합성 평가 및 보증심사를 수행하고 신용보증서 발급. [한국NGO신문](https://www.ngonews.kr/news/articleView.html?idxno=231766) · [이지경제](https://www.ezyeconomy.com/news/articleView.html?idxno=236809)
- **우리은행 역할**: 감축효과·K-택소노미 적합성이 확인된 기업에 이자지원·우대금리·보증료 지원
- **평가**: 우리은행은 데이터를 만들지 않음. 기보라는 외부 기관의 심사 결과를 대출 조건에 반영하는 소비자(consumer) 포지션 — 7곳 중 데이터 생산 주체성이 가장 낮음

### NH농협 — 금융자산 탄소배출량 측정시스템 + 전 계열사 녹색여신 심사시스템

> ⚠️ 아래 내용의 출처 기사는 2026-07-31로 추정(URL 패턴 기준) — 결선 발표(8월 말) 기준 불과 3주 전 뉴스. 심사위원이 알고 있을 가능성이 있으니 숙지할 것. [한경 매거진](https://magazine.hankyung.com/business/article/202607316744b)

- **금융자산 탄소배출량 측정시스템**: 2024년 구축, GHG Protocol + PCAF 방법론 적용, 탄소중립 목표·감축 로드맵 관리용. 신한과 동일하게 은행 내부 포트폴리오 공시용 — 기업용 화면 아님
- **2025년 신규 — 전 계열사 녹색여신 심사 시스템**: 금융권 최초로 여신을 취급하는 모든 계열사(농협은행·농협생명·농협손해보험·NH투자증권·농협캐피탈·NH저축은행)에 공통 녹색여신 심사 프로세스 + K-Taxonomy 적합성 판단 시스템을 구축. 금융위 녹색여신 관리지침 기준으로 활동·인정·배제·보호 기준을 자동 검토
- **자동 추천 기능**: 기업의 업종·제품 정보를 활용해 관련 녹색경제활동을 자동으로 추천하는 데이터 기반 기능까지 갖춤. 다만 이는 K-택소노미 적합성 분류(이 활동이 녹색인지 아닌지 판정)이지, 탄소 배출량 정량화(전표 기반 실측 계산)가 아님 — 감탄과 겹치는 지점이 아니라는 걸 발표에서 명확히 구분해야 함
- **기후패키지 금융 / 녹색정책금융 이차보전 협약대출**: 저탄소 설비자금 조달 시 금리우대, 기보 심사 기반 — 우리은행과 거의 동일한 구조. [머니투데이](https://www.mt.co.kr/finance/2026/06/25/2026062517014184681)

### IBK기업은행 — IBK ESG정밀진단 시스템

- **출시**: 2025년 5월, 중소기업 맞춤형. [전자신문](https://www.etnews.com/20250512000292) · [이지경제](https://www.ezyeconomy.com/news/articleView.html?idxno=213251)
- **구성**: 'ESG정밀진단 컨설팅' + '온실가스 인벤토리 구축 컨설팅'
- **온실가스 인벤토리 구축 컨설팅**: 기업 자체 배출량 + 공급망 내 협력사 탄소 배출량까지 측정·분석, 외부 공인 인증기관의 제3자 인증 획득
- **성격**: 자가진단 툴은 있지만 실제 인벤토리 구축은 "컨설팅" — 사람이 개입하는 서비스로 판단됨(자동화 정도 확인 안 됨)
- **왜 중요한가**: IBK는 중소기업 특화 국책은행으로 감탄의 타깃 고객군과 가장 겹침. 비교표에서 빠지면 "왜 가장 유사한 은행은 안 봤냐"는 심사 질문에 취약

### iM뱅크 — 조각난 인프라

**① ESG자가진단 및 온실가스 계산기 (2026-01-28 출시)**
리빗(LIVIT) 협업, 문진형 자가진단 + 최소입력 계산기, 기업뱅킹 앱/웹. [FETV](https://www.fetv.co.kr/news/article.html?no=211081) · [이투데이](https://www.etoday.co.kr/news/view/2550274) — 출시 7개월차, 검증 안 된 초기 서비스

**② K-Taxonomy 적합성 판단 시스템 (자체개발, 지속가능경영보고서 p.43)**
2023년 금감원과 실무적용 시스템 공동개발 → iM뱅크가 녹색분류체계 적합성 판단 시스템을 자체 개발, 기업여신 심사에 실제 적용 중. 전산 등록·스캔 관리체계로 녹색여신 적합성 판단·녹색채권 발행·녹색 PF 사전검토에 활용

**③ ESG 연계 여신상품 (p.43-44)**
- ESG Grow-Up 특별대출: 잔액 2023년 1,654억원 → 2024년 1,969억원 → 2025년 1,624억원. E/S/G 내부평가 충족 기업 금리우대+컨설팅. 대상 기준은 환경(한국환경산업기술원 BBB등급 이상 또는 ISO14001), 사회(사회적경제기업·일자리 창출), 지배구조(지배구조 공시)
- K-택소노미 연계 지원대출 / 탄소중립 경영확산 지원대출: 기보·신보와 각각 업무협약(K-택소노미 연계 녹색여신 활성화, 한국형 녹색분류체계 적합성 판정지원) 체결, 보증료 감면·한도 우대·적합성 평가 간소화. 심사 백엔드는 ②의 자체 K-Taxonomy 시스템(영업점 판단·승인신청 → ESG기획팀 적합성 판단 → 승인 → 사후 모니터링)
- iM EV론: 대구·포항 한정 전기차 구매자 저금리 대출 — 셋 중 유일하게 지리적으로 대구·경북에 이미 한정된 상품

**④ 그룹 차원 PCAF 기반 Scope 3 공시 (p.51)**
2022년 SBTi 승인, PCAF 방법론 기반 금융배출량 매년 공시. 2025년 익스포저 36.1조원, 배출량 6,701,732 tCO2e

**⑤ 환경영향평가 체크리스트 (p.45)**
전체 기업여신 신청 기업의 97%(20,161건)가 A~F 6등급 환경리스크 평가 기반 심사 적용

**핵심 진단**: iM은 ①~⑤ 다섯 개 트랙을 각각 갖고 있지만 서로 연결이 안 돼 있음 — ①(고객용 계산기)은 ②③④⑤(내부 심사·상품·공시 인프라)와 별개로 굴러감. "iM은 기술이 없다"가 아니라 "iM은 파편화돼 있다"가 정확한 표현.

**ESG Grow-Up 대출 잔액 추이의 함의**: 2024년 정점(1,969억) 후 2025년 감소(1,624억) — 성장 상품이 아니라 정체·소폭 위축 국면. 발표에서 "이미 잘 되고 있는 상품"으로 인용하기보다, "좋은 인프라가 있는데도 확장이 안 되고 있다 → 감탄이 실측 데이터로 대상 기업 발굴을 쉽게 만들면 이 숫자를 다시 키울 수 있다"는 논리로 뒤집어 쓰는 편이 안전함. 마찬가지로 "K-Taxonomy 적합여신 발굴실적" 포상 이벤트(2025.4~10)가 열렸다는 것도 발굴이 아직 더딘 상태라는 방증 — 감탄이 전표 실측 데이터로 "이 기업이 K-Taxonomy 적합 후보"를 자동으로 걸러주면, 지금 영업점이 수작업으로 하는 발굴 작업을 대체·보완할 수 있음.

## 3. iM 포지션 — 뒤처진 지점 / 유리한 지점

### 뒤처진 지점

1. 입력 부담이 KB보다 큼 — KB는 계정연결 후 대체로 자동(전기 한정)인데, 감탄은 마이데이터 5종 자동 + 서류 업로드 필요
2. iM 그룹 PCAF 자체는 신한과 비슷한 시기(2022)부터 있었지만 감탄과는 완전히 별개 트랙 — 그룹 차원 하향식 공시 실적은 있어도, 감탄이 만드는 "전표 기반 상향식 데이터 + 규제대응 리포트"는 이제 설계 단계. 트랙 레코드가 없는 게 아니라 연결이 안 된 것
3. 학술적 검증 레이어 부재 — 하나은행의 이대+금감원 검증 같은 제3자 검증 서사가 감탄엔 아직 없음
4. IBK와 타깃 고객군이 정확히 겹침 — IBK는 이미 협력사 배출량까지 다루고 제3자 인증까지 받음
5. NH 2025년 전 계열사 자동추천 시스템 — "은행 내부용이라 자동화 약함" 논리가 NH 앞에서 안 통함(단, K-Taxonomy 분류이지 정량화가 아니므로 구분해서 말할 것)
6. iM 스스로도 조각난 인프라 문제를 아직 못 풀었음 — K-Taxonomy 시스템·ESG Grow-Up 대출·PCAF 공시·온실가스 계산기가 4개 다 따로 있다는 건, iM 내부 통합 시도가 아직 안 됐거나 실패했다는 뜻일 수 있음. "우리도 어려운 걸 하는 거다"라고만 말하면 "그럼 왜 지금까지 iM이 못 했냐"는 역질문에 취약 — 누가/왜 지금 통합해야 하는지(감탄의 존재 이유)를 명확히 설명해야 함

### 유리한 지점

1. 비정형 텍스트(Scope 1) AI 해석은 7곳 전부 미확인 — 유일하게 그대로 유효한 명확한 공백. 세금계산서 품목명을 OCR+LLM으로 분류·근거 생성하는 곳은 없음
2. 감탄은 "새로 만드는" 게 아니라 "iM이 이미 가진 조각을 연결하는" 프로젝트다 — K-Taxonomy 판단(②)·여신상품(③)·PCAF 공시(④)·환경평가(⑤)가 이미 존재. 감탄의 전표 기반 실측 데이터가 이 네 개를 관통하는 입력값이 되면, 신규 구축이 아니라 기존 투자의 완성이라는 저비용·저리스크 서사가 됨
3. 기업 화면 + 은행 담당자 화면이 하나의 파이프라인으로 연결된 구조는 여전히 유니크 — 신한·NH는 은행내부용(기업화면 없음), iM은 화면(①)과 백엔드 인프라(②③④⑤)가 있어도 서로 분리. 이 둘을 잇는 감탄의 HITL 큐 → 승인요청 큐 → 포트폴리오 히트맵 → 감사대응 패키지 구조는 7곳 어디도 보도자료에 없음
4. 여신 구조상 동기가 가장 강함 — §6의 DART 대조 수치 참고
5. 감사대응 근거패키지는 신한·NH·iM의 하향식 PCAF 시스템 어디로도 못 만듦(원본 전표가 없기 때문) — 구조적으로 감탄만 가능한 산출물

## 4. 발표에서 써야 할 정확한 문장

**쓰면 안 되는 것:**
- "저희는 업계에서 유일하게 입력 없이 자동으로 측정합니다" — §7 실제 흐름(마이데이터 자동 확보 + 연료 유형 직접 체크 + 필요 시 서류 업로드)과 어긋남
- "KB보다 저희가 훨씬 편합니다" — KB의 전기 자동인식과 정면 비교하면 오히려 불리한 지점이 있음(§3 뒤처진 지점 1)
- "iM뱅크는 원화대출의 52%가 중소기업입니다" — DART 대조 결과 근거 없는 수치, §6 참고
- "iM뱅크는 여신 연계 상품이나 국제표준 방법론이 없습니다" — 사실이 아님. ESG Grow-Up 대출·K-택소노미 연계대출·그룹 PCAF 공시가 이미 있음. "없다"가 아니라 "따로 있고 안 연결됐다"가 정확한 표현

**쓸 수 있는 것:**
- "저희가 조사한 7개 은행 중 세금계산서의 비정형 텍스트를 AI가 읽어 Scope 1을 자동 분류하는 서비스는 없었습니다."
- "iM뱅크는 이미 K-택소노미 자체 판단 시스템, ESG 연계 대출상품, 그룹 차원 PCAF 공시를 각각 갖고 있습니다. 감탄은 이걸 새로 만드는 게 아니라, 세금계산서에서 나온 실측 데이터로 이 조각들을 하나의 파이프라인으로 연결하는 작업입니다."
- "iM뱅크는 총여신의 63.2%가 기업 대상이고, 기업대출 연체율(1.12%)이 가계(0.46%)의 2배가 넘습니다. 대구·경북 지역에 원화대출의 72%가 몰려 있어, 이 지역 소부장 기업의 공급망 이탈은 저희 자산건전성에 직접적인 영향을 줍니다."

## 5. 왜 자체 시스템을 개발해야 하는가 — 외부 솔루션 대비

1. **벤더 락인 회피**: 리빗(LIVIT)은 B2B 솔루션 업체 — 오늘 iM이 쓰는 계산기를 내일 KB나 신한이 살 수도 있음. iM만의 moat를 만들려면, 리빗을 쓰는 다른 은행이 못 따라오는 것 — iM만 갖고 있는 데이터(대구·경북 소부장 기업의 실제 전표)와 iM만 만든 파이프라인의 결합이 필요함
2. **규제 대응**: 저신뢰 건이 왜 HITL로 갔는지, 이상치를 왜 정상으로 판정했는지 감독당국에 설명해야 하는데, 외부 벤더의 계산 로직이 블랙박스면 iM은 남의 알고리즘을 설명하는 처지가 됨. 자체 개발이면 trace_logs·evidence 저장 방식을 iM이 설계하므로 판단 근거를 iM이 통제·설명 가능
3. **커스터마이징 한계**: 벤더는 여러 은행에 같은 제품을 파는 게 사업모델이라 iM만을 위한 깊은 커스터마이징(비정형 텍스트 해석, 결손 자동감지, 포트폴리오 히트맵, 감사대응 패키지) 유인이 낮음. 지금 iM의 리빗 협업 서비스가 "문진형 자가진단 + 최소입력 계산기" 수준에서 멈춰있는 것도 이 구조 때문일 가능성이 큼
4. **비용 곡선의 방향**: 자체 개발은 초기 고정비가 크지만 사용자가 늘어도 한계비용이 낮음(llm_cache로 비용 직접 통제). 외부 SaaS는 초기 비용은 작지만 건별/API콜별 과금이면 규모가 커질수록 비용이 계속 불어나고, 가격·계약 조건을 iM이 통제 못 함. 결선(300건) → 실서비스(대구·경북 소부장 기업 전체)로 확장할수록 이 차이가 커짐
5. **자산화**: 자체 파이프라인으로 쌓인 데이터(분류 결과, 배출계수 매핑, 트레이스 로그)는 iM의 자산이 되어 여신심사·리스크관리·ESG 공시 등에 재사용 가능. 외부 솔루션 결과값은 계약 종료 시 iM 손에 남는 게 없거나, 애초에 원본 데이터·모델이 iM 소유가 아님

**균형 잡힌 시각**: 외부 솔루션의 진짜 장점은 출시 속도(리빗은 이미 검증된 계산 로직 보유)·초기 개발비 절감·완성도(전문 업체의 환경 도메인 지식). iM이 지금 이 방식을 택한 것도 "일단 빠르게 뭔가는 갖춰야 한다"는 합리적 선택이었을 것.

**발표용 정리**: "외부 솔루션은 빠르게 시작하기엔 맞는 선택이지만, 이게 은행의 핵심 여신·규제 대응 인프라가 되려면 얘기가 다릅니다. 신한·NH·KB가 이미 자체 개발로 간 것도, NH가 2025년에 전 계열사 시스템까지 자체 구축한 것도 같은 이유입니다 — 이건 사올 물건이 아니라 만들어야 하는 물건입니다."
